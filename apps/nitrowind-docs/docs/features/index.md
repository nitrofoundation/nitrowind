# Features

Nitrowind brings Tailwind CSS v4 utilities to React Native while keeping responsive and state-dependent updates in the native runtime.

## Styling and components

- [Components](/features/components) covers supported React Native primitives and className behavior.
- [States and Groups](/features/states-and-groups) documents interaction and group variants.
- [Native Props](/features/native-props) explains native prop mappings.
- [SVG](/features/svg) covers className styling for React Native SVG elements.

## Responsive layouts

- [Responsive and Containers](/features/responsive-and-containers) introduces responsive variants.
- [Container Queries](/features/container-queries) adapts components to their parent size.
- [Safe Area](/features/safe-area) exposes device insets through utilities.

## Visual features

- [Background Images](/features/background-images) covers sizing, positioning, and repeat behavior.
- [Gradients and Backgrounds](/features/gradients-and-backgrounds) documents native backgrounds.
- [Effects](/features/effects) and [Animations](/features/animations) cover native visual updates.

See [Nitrowind-Specific Features](/features/nitrowind-specific) for capabilities that go beyond a standard React Native Tailwind className layer.
