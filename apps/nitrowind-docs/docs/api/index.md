# API

Use these references when integrating Nitrowind with application code, third-party components, Metro, or build tooling.

- [Runtime API](/api/runtime) documents providers, hooks, theme state, and runtime updates.
- [Component API](/api/components) lists the className-aware React Native components.
- [cssInterop](/api/css-interop) maps class names onto third-party component props.
- [Compiler API](/api/compiler) documents the Node-only compiler surface.
- [Metro API](/api/metro) covers the Metro configuration wrapper and options.

Start with [Installation](/getting-started/installation) if Nitrowind is not configured in your project yet.
