# API

Use these references when integrating Nitrowind with application code, third-party components, Metro, or build tooling.

- [Runtime API](/docs/api/runtime) documents providers, hooks, theme state, and runtime updates.
- [Component API](/docs/api/components) lists the className-aware React Native components.
- [cssInterop](/docs/api/css-interop) maps class names onto third-party component props.
- [Compiler API](/docs/api/compiler) documents the Node-only compiler surface.
- [Metro API](/docs/api/metro) covers the Metro configuration wrapper and options.

Start with [Installation](/docs/getting-started/installation) if Nitrowind is not configured in your project yet.
