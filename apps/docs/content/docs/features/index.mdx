# Nitrowind Features for React Native

Each supported capability has a focused page with examples, native behavior, web behavior, and current platform boundaries.

<Callout type="info" title="Native updates are the differentiator">
  Runtime-dependent styles can move through Nitrowind's native dependency graph instead of being
  resolved again on the JavaScript thread.
</Callout>
